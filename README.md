# 📱 React Native App

Welcome to the **React Native App**! This is a cross-platform mobile application built with modern tools and best practices for scalability, maintainability, and developer experience. 🚀

---

## 🛠 Tech Stack

- **React Native** — Cross-platform mobile framework
- **Expo** — Development platform for React Native apps
- **TypeScript** — Strongly typed JavaScript for safer development
- **React Router** — Navigation and routing
- **Zod** — Type-safe schema validation ✅
- **useForm** — Elegant form management
- **Apollo Client (GraphQL)** — Data fetching, mutation and state management
- **JWT Authentication** — Implemented via Apollo Link (middleware-like approach)
- **Custom Hooks** — For clean separation of logic and presentation 🧠➕🎨

---

## 🔐 Authentication

Authentication is handled using **JWT tokens** via **Apollo Link**, which intercepts requests and injects tokens into headers — similar to middleware in traditional applications.

---

## 🧱 Architecture

- **Custom Hooks** encapsulate business logic.
- **Presentation Components** are kept clean and focused on UI rendering.
- Forms are validated using **Zod** integrated with `useForm`.
- Navigation is managed through **React Router**, providing a familiar web-like routing experience.
